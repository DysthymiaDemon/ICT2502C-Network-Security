# ICT2502C-Network-Security
AY2023/24 Trimester 3 Assignment on Real-World Network Attacks and Defenses


This assignment delves into the security vulnerabilities of OSPF, focusing on becoming a rogue OSPF router neighbour, its implications, and the defences against it. It provides details on the network attacks done, the outcomes of such attacks and mitigation measures one can take to prevent such attacks from succeeding.
